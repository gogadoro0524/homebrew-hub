# worktory Homebrew Tap

Install the signed and Apple-notarized worktory desktop app on Apple Silicon macOS:

```bash
brew install --cask gogadoro0524/hub/worktory
```

Upgrade later with:

```bash
brew upgrade --cask gogadoro0524/hub/worktory
```

The Hub source repository remains private. This public tap contains only the
Homebrew Cask and the notarized desktop release archives needed for installation.
