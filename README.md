# blueberry Homebrew Tap

Install the signed and Apple-notarized blueberry desktop app on Apple Silicon macOS:

```bash
brew install --cask gogadoro0524/hub/blueberry
```

Upgrade later with:

```bash
brew upgrade --cask gogadoro0524/hub/blueberry
```

The Hub source repository remains private. This public tap contains only the
Homebrew Cask and the notarized desktop release archives needed for installation.

Existing worktory, agos, and bkgd installations migrate through Homebrew cask renames. Run `brew update` before upgrading. Saved application data is preserved on ordinary upgrades.
