# agos Homebrew Tap

Install the signed and Apple-notarized agos desktop app on Apple Silicon macOS:

```bash
brew install --cask gogadoro0524/hub/agos
```

Upgrade later with:

```bash
brew upgrade --cask gogadoro0524/hub/agos
```

The Hub source repository remains private. This public tap contains only the
Homebrew Cask and the notarized desktop release archives needed for installation.
